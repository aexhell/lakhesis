After my [first serious project](/projects/moon), I was invited by [Saektide Works](https://xaeky.cloud/) to do volunteer front-end at [Puroto](https://github.com/purotoapp), a social media for furries. I programmed its user profile interface and left the team three months after. Overall it was great to learn more about front-end.

Despite the project having ended more than five years ago (and the code we did is not available anymore), you can check its GitHub organization that has its revamped code available.
